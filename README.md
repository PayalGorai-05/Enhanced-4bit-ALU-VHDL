# Enhanced 4-bit ALU using VHDL

## Overview

This project implements a 4-bit Arithmetic Logic Unit (ALU) in VHDL. The design performs arithmetic, logical, and shift operations and generates Carry and Zero status flags.

## Operations Implemented

| SEL | Operation |
|------|-----------|
| 000 | Addition |
| 001 | Subtraction |
| 010 | AND |
| 011 | OR |
| 100 | XOR |
| 101 | Shift Left |
| 110 | Shift Right |

## Features

- Arithmetic Operations
- Logical Operations
- Shift Operations
- Carry Flag Generation
- Zero Flag Generation
- Behavioral Simulation Verification

## Tools Used

- VHDL
- Xilinx Vivado

## Learning Outcomes

- RTL Design
- Combinational Logic Design
- Digital System Verification
